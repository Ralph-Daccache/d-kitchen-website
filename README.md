## Design System: Heritage Modernism

### Brand Philosophy
This design system is rooted in architectural precision and a three-generation legacy of excellence, communicating modern luxury through "Formal Minimalism." Every element is deliberate, and nothing is superfluous.

### Color Palette
- **Primary:** Vibrant Lime Green (#8CC63F) - Reserved for CTAs and key accents
- **Surface:** Deep Black (#131313) - Main background
- **Text:** Off-white (#e5e2e1) - Primary text color
- **Neutral:** Dark Grey (#1A1A1A) - Secondary containers and borders

### Typography
- **Headlines:** Noto Serif (elegant, authoritative)
- **Body:** Manrope (modern, geometric)
- **Labels:** Manrope uppercase with increased letter spacing

### Shape Language
- **Strictly Sharp (0px)** - No border radius, reflecting high-end kitchen cabinetry precision

### Key Components
- **Primary Buttons:** Sharp-edged, lime green background
- **Ghost Buttons:** White border with white text
- **Input Fields:** Minimalist underscore style with white bottom border
- **Cards:** Image-first layout with text below
- **Navigation:** Thin, fixed header with label-caps typography
